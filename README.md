# 🍔 Da Família Lanches - V2

Sistema de delivery moderno desenvolvido para a **Da Família Lanches**, focado em experiência do usuário, agendamento de pedidos e fidelização.

## 🚀 Tecnologias Utilizadas

* **Framework:** [Next.js](https://nextjs.org/)
* **Linguagem:** TypeScript
* **Estilização:** Tailwind CSS
* **Banco de Dados/Auth:** Firebase
* **Deployment:** Vercel

## ✨ Novas Funcionalidades

* ✅ **Sistema de Agendamento:** Controle de horários de abertura e fechamento.
* ✅ **Fidelidade:** Sistema de pontos para clientes recorrentes.
* ✅ **Gestão de Cupons:** Aplicação de descontos no carrinho.
* ✅ **Checkout via WhatsApp:** Integração direta para finalização do pedido.
* ✅ **Painel Administrativo:** Gestão de produtos e estoque em tempo real.

## 🛠️ Como rodar localmente

1.  Clone o repositório:
    ```bash
    git clone [https://github.com/seu-usuario/da-familia-lanches-v2.git](https://github.com/seu-usuario/da-familia-lanches-v2.git)
    ```
2.  Instale as dependências:
    ```bash
    npm install
    ```
3.  Configure o arquivo `.env.local` com suas chaves do Firebase.
4.  Inicie o servidor de desenvolvimento:
    ```bash
    npm run dev
    ```
