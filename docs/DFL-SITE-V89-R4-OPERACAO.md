# V89 R4 — Agendamentos prioritários na operação

- A Home do Admin mostra aviso compacto quando existem agendamentos cujo horário chegou, sem obrigar o operador a abrir a aba para descobrir.
- Botão direciona para a aba Agendados com filtro "Somente vencidos", limpando outros filtros que poderiam esconder resultados.
- Os dados vêm da mesma fila operacional; nenhum read extra, polling adicional ou mudança automática de status.
- Foco mobile e acessibilidade por teclado protegidos.
